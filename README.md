# Pulse Analytics

A responsive analytics dashboard prototype built with React, TypeScript, Tailwind CSS v4, Lucide icons, and Recharts.

## Run locally

```bash
npm install
npm run dev
```

Run `npm run build` to create a production build and `npx tsc --noEmit` to check TypeScript types.

## Included interactions

- Date range and platform filters with loading skeletons and simulated retryable network errors
- Revenue and cost chart with independently toggleable series
- KPI detail dialogs and sortable transactions
- Command palette with `Ctrl+K` / `⌘K`, customer search, and CSV export
- Responsive sidebar, keyboard focus styles, reduced-motion support, and screen-reader announcements
